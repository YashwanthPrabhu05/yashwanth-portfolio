# Portfolio Recreation

A static portfolio website built with HTML, CSS, and JavaScript. The root page is `index.html`; the Zeno, ShopEZ, and GameON case studies are in their own folders.

## Run locally

Install the existing project dependencies and start the Vite development server:

```powershell
npm install
npm run dev
```

The site can also be served directly from this folder with any static HTTP server.

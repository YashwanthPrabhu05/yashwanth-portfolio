# Yashwanth Prabhu — Portfolio Website

A static portfolio website built with HTML, CSS, JavaScript, and Vite.

## Managing Portfolio Content

All portfolio content is centralized in **`portfolioData.js`**. You do **not** need to manually edit HTML templates or CSS to update content.

Simply edit `portfolioData.js` to change:
- **Hero section**: introduction, positioning, CTAs
- **Featured project**: Gradian details, highlights, key metrics
- **Selected projects**: SwiftPay, FinMate, CREA, Catalyst Hub, Interface Explorations
- **Achievements & Flex**: competitions, hackathons, certifications
- **About me**: bio, personal facts, toolkit categories (Design & Prototyping, AI & Development)
- **Design journey**: Fyrasoft, Tems Tech Solutions, college education
- **Contact**: recipient email, form labels
- **Social links**: LinkedIn, Behance, Framer, Email, Resume

## Run locally

Install the existing project dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
